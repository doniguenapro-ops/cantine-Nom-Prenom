Projet : La caisse de la cantine

1. Présentation

La caisse de la cantine est un programme développé en JavaScript qui permet de gérer les commandes des clients d'une cantine. Il calcule le montant total à payer en fonction du plat choisi et de la quantité commandée, puis vérifie le paiement effectué.

2. Menu de la cantine

Le programme propose trois plats :

Code 1 : Attiéké-poisson — 1 500 FCFA

Code 2 : Riz-poulet — 2 000 FCFA

Code 3 : Alloco-œuf — 1 000 FCFA

3. Fonctionnalités

Le programme permet de :

Enregistrer le nom du client, le code du plat, la quantité et le montant versé.

Déterminer le prix unitaire du plat choisi.

Calculer le montant total de la commande grâce à une fonction.

Afficher chaque portion commandée à l'aide d'une boucle for.

Calculer la monnaie à rendre ou le montant restant à payer.

4. Technologies utilisées

JavaScript : langage de programmation.

Node.js : environnement d'exécution du programme.

Visual Studio Code : éditeur de code.

Git : outil de gestion des versions.

5. Exécution du programme

Pour exécuter le programme, ouvrir un terminal dans le dossier du projet et saisir la commande suivante :

node cantine.js
